# Assemblée synchrone

Combiner dans Inseme : bâton de parole, Ophélia / Monsieur Loyal, terrains féconds.

> Le bâton de parole règle le temps de parole. Les terrains féconds règlent le terrain du désaccord. L’assemblée reste souveraine.

## États

- `speechQueue` : qui veut parler.
- `talkingStick` : qui parle maintenant.
- `fertileGround` : terrain cognitif du débat.
- `debateMap` : mémoire structurée.
- Ophélia : facilitation et synthèse.
- Humains : décision.

## Sortie vers l’asynchrone

Fin de séance : synthèse, propositions, objections ouvertes, terrains féconds proposés, décisions prises, continuations.

> Le synchrone rend la parole vivante ; l’asynchrone rend la pensée vérifiable.
